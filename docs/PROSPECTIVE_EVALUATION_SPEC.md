## Scope and frozen defaults

Research-only, `executable=false`. No orders, broker account reads/writes, reset, purchases, global Hermes changes, production deployment or scheduler installation. Initial default universe remains SPY/QQQ/IWM/AAPL with existing etf/equity classes. User may register another validated US-equity universe. Explicit synthetic research cash is an arithmetic book, not a spending cap/account balance.

Four arms: zero-yield `cash`, `equal_weight`, `sma20`, `ai_three_role`. Trend assigns each symbol its original equal-weight slice only if last completed close is strictly above the last20-session Decimal SMA; otherwise that slice stays cash. Existing21-session normalization suffices; do not introduce a60-session prerequisite. Equal weights rounded down to12 decimal places, residue cash. All arms use the same source bundle/input fingerprint. AI uses existing three-role public lab, exact registered requested model, max3calls, no fallback. Preserve raw accepted CIO artifacts; effective cohort cash is exactly1 minus validated target weights under the fixed arithmetic context, retaining any tolerated under-sum as residual cash. Failed/blocked/abstained/missing AI remains unavailable, **not a cash decision**; reports retain missingness/denominators rather than comparing only successful winners invisibly.

Horizons `[1,5]`, including anchor session as1. No20-session addition. Missing entry/exit bar means pending/unavailable, never assumed cash/non-fill/forward-fill. Every raw response is `price_only`, `corporate_action_status=unchecked`, `economically_scorable=false`. No P&L, adjusted total return, after-cost alpha, ranking/promotion, significance, annualization, or compounded overlapping-cohort equity claim.

## Source/clock contract

Official bars/FAQ: daybar `t` is New York interval midnight; `o` first eligible OHLC update, not first unfiltered trade or09:30/official auction. `feed=iex`, `adjustment=raw`, `asof=-`, `currency=USD`, `timeframe=1Day`, ascending, limit10000; terminal-null pagination required. Calendar GET paper `/v2/calendar` with inclusive dates and `date_type=TRADING`, timezone-aware returned extended session close. Existing allowlisted transports only; no new trade/quote/corporate-action endpoint needed for this non-economic study.

For slot T, obtain next five trading rows A…H5 from an actually received future calendar. T extended close must be strictly before collection/decision. Campaign registration and all checkpoint input/proposal publication must precede A New York midnight strictly. T is latest completed calendar session and A immediately follows it; after A midnight, never backfill T. Weekend window may extend until Monday midnight: actual collection/freeze clocks stay actual, never relabelled Friday forecasts. No CLI clock overrides. Existing300-second snapshot freshness and900-second bundle expiry remain authoritative through model latency; additionally reject a decision completed at/after A midnight.

Freeze the five planned outcome rows before inference, not after seeing prices. `decision_deadline = min(bundle.as_of + 300 seconds, A.interval_start - 1 microsecond)`; it is strictly earlier than anchor midnight, NOT anchor midnight itself. Final completion must be strictly before this deadline and A midnight. An interval-start-equal-to-deadline bar is inadmissible. Outcome bars must match A/H target dates and be fetched strictly after their returned extended closes. Fetch/receipt clocks are availability; `source_published_at=null`. Calendar revisions/missing rows are flagged/unavailable rather than silently shifting horizons to favorable dates. Source price revisions remain append-only; first-observed and latest-observed raw responses distinct. First-observed entry anchor remains fixed across horizons. No completeness/immutability promise from REST or body hashes.

## Public interfaces and ownership

All modules under `scripts/prospective_evaluation/`, canonical imports `prospective_evaluation.*`. Public-seam red→green TDD; no private limit mutations/helpers, ignore/exclusion shortcuts, or alternate `scripts.*` namespace.

### Protocol/storage module

`protocol.py`: `prepare_protocol(request) -> frozen_protocol`; `validate_protocol(frozen_protocol) -> frozen_protocol`. Request exact keys: `schema_version:1`, `campaign_id` portable ID, `universe` list1..20 exact symbol/asset_class pairs (equity/etf), `model` bounded string, `research_cash` positive finite bounded decimal string, `max_checkpoints` exact int1..252. Full frozen protocol adds exact recipe/defaults above, observation cadence900seconds, max_campaign_days90, horizons, arms, source/missing/cost/promotion policies. No caller timestamps/outcomes/imported runs. Reject bool-as-int, malformed containers, unknown fields, unsafe IDs, duplicate symbols, crypto.

`storage.py`: `register_campaign(root, request, *, clock=None) -> Path`; `load_campaign(path) -> registration`; `implementation_fingerprint() -> str`; `campaign_lock(path)` nonblocking context manager, raises `CampaignBusy`; `write_record(path, kind, record_id, value) -> record`; `load_records(path, kind) -> list[record]` sorted. Registration = schema_version1/protocol/registered_at/implementation_fingerprint; system UTC clock unless injected test clock. Create-once registration/hash manifest, kind directories and artifacts dir. Kinds exactly `events`, `observations`, `checkpoints`, `ticks`. Record envelope = schema_version1/kind/record_id/value/sha256 (hash canonical value). Bounded strict JSON4MB, safe paths/no symlinks/duplicate keys/nonfinite values, atomic durable create-once publication, never overwrite. Exclusive OS lock releases on process death. Caller holds campaign_lock for whole tick; record publication remains independently create-once. Integrity is not authentication against privileged coordinated rewrites. Source fingerprint covers production evaluation/evidence/lab Python (not tests). No global infrastructure edits.

### Observation module

`observations.py`: `observe_market(symbols, start_date, end_date, alpaca, *, clock=None, max_pages=16) -> observation`; `reconstruct_observation(observation) -> normalized`. Calendar query spans supplied strict dates, max370days; bars start at start_date NY midnight and end at actual collection start (never future end_date). Bound symbols/pages/records; project metadata only; sanitize exceptions/upstream bodies. Retain complete/failed sources and partial receipts. Observation root: schema_version1, symbols, started_at, completed_at, start_date, end_date, policy (five exact bar fields), sources (`sessions`,`bars`, existing pages/complete/error shape). Query and receipt/page chronology fully verified offline. `reconstruct_observation` yields `{sessions:[{date,interval_start,session_close_at}], bars:{symbol:[{session_date,interval_start,session_close_at,open,close,available_at,source_published_at:null}]}, completed_at}`; reject failed capture with a stable public `ObservationError`. Calendar includes future rows, bars normalize only fully completed sessions with strict request>close. Future/unknown dates, non-midnight day labels, invalid OHLC/nonfinite/negative values/conflicting duplicates/query/pagination corruption fail closed. Missing symbol bars allowed (explicit missing outcome), not fabricated. Full raw projected observations retained separately from normalized output. No news/BEA retrieval here.

### Deterministic measurement module

`measurement.py`: `baseline_allocations(protocol, bar_inputs) -> arms`; bar_inputs is public normalize_market()['bar_inputs']; result maps cash/equal_weight/sma20 to `{status:'accepted',targets:[{symbol,weight}],cash_weight}`. `score_checkpoint(protocol, checkpoint, observations) -> result`: checkpoint shape below, observations list of raw observation captures; validates/reconstructs all source records using public observation seam. Returns per-horizon status/pending/unavailable/raw_response (not economic return), first/latest observation provenance, symbol responses and arm responses/paired control differences. Failed arms have null response and original status. No performance aggregates beyond counts/coverage. Deadline/maturity/calendar/entry/missing/currency/future provenance checked; unknown costs never zero. Use Decimal, explicit modest precision and deterministic strings. Stable public `MeasurementError`. Future fixtures distinctly synthetic in tests, not actual-run evidence.

### Runner module

`runner.py`: `tick(path, alpaca, public, provider, *, clock=None) -> receipt`; `report_campaign(path) -> dict`; `verify_campaign(path) -> dict`. Acquire campaign_lock; verify registration/runtime identity and monotonic clocks. Tick ID is UTC900second start bucket. Completed tick repeats return saved receipt, no source/model calls. Persist event `tick-<id>-started` BEFORE external work; never blindly repeat an ambiguous started tick. Persist immutable observation per tick before use. Start range registration NY date minus10days; end current NY date+30days, bounded90-day campaign. Once max_checkpoints frozen/missed, collect only needed pending outcomes; after90days terminal unavailable not forever pending. Every tick bounded, no timer loop/install.

A slot is current latest completed T with five following calendar rows and `now < A.interval_start`; skip/backfill nothing after deadline. Missed slots after registration stay visible (events/coverage), not manufactured predictions. Before source collection/inference, reserve fixed per-session event; after actual collect_sources/build_collection/write_collection (under artifacts/collections), persist deterministic controls and source/bundle reference. Persist `inference-<T>-started` BEFORE run_lab; after crash, infer at most once: recover valid existing published lab artifact via replay or mark in_doubt with unknown charge, never retry. Unfinished reservations count visibly, not silently dropped. Model phase uses default actual clock via callable; no timestamp freezing across latency.

Final checkpoint: schema_version1, slot_date, collection_id, bundle_hash, collection_path (safe relative under artifacts), decision_path (safe relative or null), source_session_close_at, bundle_as_of (exact collection.bundle.as_of), decision_deadline (min(bundle.as_of+300s,A midnight minus1microsecond)), inputs_frozen_at, frozen_at (actual completion), outcome_sessions (five normalized rows), arms (all four; AI status/reason/targets/cash_weight), model_receipts. `frozen_at < decision_deadline` mandatory for prospective scoring; additionally require the finalized tick's post-checkpoint publication witness strictly before the deadline. Missing witness is publication_unconfirmed; actual recovery/publication at or after deadline remains late. Every control must reproduce from the exact collection; accepted AI vector must match public replay with deterministic residual cash, not arbitrary recorded weights. Failed arm target vectors null, never synthesized cash. No real economic outcome/net costs without evidence.

Reports verify record integrity, reconstruct each observation/collection and decision, recompute controls and all scoring without network/provider access, stable order/counts. Include reservations/missed/in_doubt states, no selection-only successful decisions. Observations permit appending future corrected versions; first-scored results reproducible, latest comparison separate. All outputs executable=false. Public CLI register/tick/report/verify wraps these seams; managed Hermes launcher reuses proven bootstrap, no global changes. CLI errors sanitized and no raw upstream/provider body.

### Managed SDK execution seam

Actual dependency probe: project Python3.13 has the evidence dependencies; installed Hermes SDK runtime Python3.14.9 has NoUS/OpenAI but **no icalendar**. Running the entire evaluator inside that closure is not a working tick. Keep campaign/evidence/scoring in the project environment; execute only the existing pure decision-lab CLI in Hermes' managed SDK closure. No global dependency installs, mixed-version site-packages or provider reconfiguration.

`execution.ManagedLabExecutor(model, *, runner=None)(bundle, collection_path, output_dir) -> decision` is the accepted public external-inference seam. Verify the archived bundle equals the exact passed bundle, discover/validate the existing managed command, run `ai_decision_lab.py run <collection>/bundle.json --model <registered-model> --output <decision-root>` once with bounded subprocess I/O/time, and read back/replay the exact published run. Core `hash_value` defines lab input hashes. Preserve accepted/blocked/failed normal CLI terminal results; unreceipted subprocess ambiguity raises stable `LabExecutionError`, never repeats. No clock override is passed to the worker. No new worker protocol or source dependencies inside the SDK process.

Runner accepts optional keyword `execute_lab=None`; direct provider tests retain `run_lab(bundle, provider, ..., now=clock)`, while production CLI supplies this whole-lab executor and `provider=None`. Before-call durable inference reservation covers either adapter. The `evaluate_prospective_hermes.py` convenience entrypoint must delegate to the project CLI, not re-execute all evidence modules inside the SDK closure. The SDK subprocess is only an inference adapter, not a new daemon or authorization path.
